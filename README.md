# Employee Salary Prediction Using Linear Regression

## Project Overview

This project predicts employee salaries based on years of experience using Python and a Linear Regression machine learning model.

## Objectives

* Analyze the relationship between experience and salary.
* Perform data cleaning and exploratory data analysis.
* Create data visualizations.
* Train a Linear Regression model.
* Evaluate model performance.
* Predict salaries for new experience values.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Dataset

* `YearsExperience`: Years of work experience.
* `Salary`: Employee salary.

## Machine Learning Workflow

1. Data loading and understanding
2. Data cleaning
3. Exploratory Data Analysis
4. Data visualization
5. Feature selection
6. Train-test splitting
7. Linear Regression model training
8. Salary prediction
9. Model evaluation
10. Residual analysis

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

## Conclusion

This project demonstrates how Linear Regression can be used to estimate employee salaries based on work experience.
